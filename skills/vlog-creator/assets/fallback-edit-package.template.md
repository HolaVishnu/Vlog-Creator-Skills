# Fallback Edit Package

## Production status

State the exact rendering or final-polish limitation once. Confirm that original media was preserved and that this package is the executable path to complete the vlog in the user's editor.

## Source inventory

List every supplied video and standalone audio source with stable ID, filename/path, duration, video specs, audio specs, status, and any probe error.

## Creative direction

Describe the target audience, platform, story promise, tone, and the final feeling the vlog should create.

## Clip decisions

For each source, provide clip ID, exact in/out time, KEEP/CUT/B-ROLL/AUDIO decision, timeline use, and beginner-friendly reason.

## Timecoded timeline

Build the complete timeline from 00:00.000 to export end. Include source IDs, source ranges, timeline ranges, dialogue or ambience use, transitions, and story purpose.

## Audio/SFX map

Specify dialogue cleanup, room tone or ambience placement, music licensing status, optional SFX, fades, loudness target, and checks for abrupt audio changes.

## Captions and graphics

List captions, title cards, lower thirds, labels, end screen, placement, timing, contrast, and any deliberate omissions.

## Travel data and on-screen information

When relevant, list location cards, route/map overlays, telemetry/data widgets, source of each fact, sync offset, attribution needs, and fallback title-card instructions if overlay rendering is unsupported.

## Color recipe

Give correction steps for exposure, white balance, matching, skin tone, and a restrained grade. Include one fallback if the selected editor lacks a named control.

## Export settings

Specify filename, output folder, platform, resolution, frame rate, codec/container, audio codec/sample rate, caption format, and upload-prep files.

## Upload package

When requested, include title options, description, chapters, tags, hashtags, and thumbnail instructions or generated thumbnail path. Do not invent names, venues, dates, songs, or rights claims that are not supported by the supplied media or user-provided context.

## Exact completion action

Give the next click-by-click action in the selected editor, then the verification gate: confirm output exists, opens with readable video and audio, matches duration/resolution/frame rate, and passes a start/middle/end review.
